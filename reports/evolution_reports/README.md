# Evolution Reports

One report per evolution pass, written by the Evolution Agent (via `/evolve`).

- **Filename:** `YYYY-MM-DD-evolution.md`
- **Contents:** system-level findings, supporting evidence, prioritized recommendations,
  any safe changes applied, and proposals awaiting user approval.

Run `/evolve` periodically (roughly every 10–20 tasks). Non-trivial recommendations are
**proposed**, not auto-applied — review them before accepting.
