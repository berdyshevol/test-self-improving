- **Summarize-and-link documentation** — when adding a doc file (`README.md`,
  `CONTRIBUTING.md`, …), write a short self-contained summary and link to the canonical
  source (e.g. `docs/self_improvement_system.md`) instead of duplicating it. Keeps a single
  source of truth and prevents drift. Observed across three documentation tasks.
